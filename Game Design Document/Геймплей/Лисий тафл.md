## Игровое поле

- Поле состоит из нечетного количества **9 × 9** квадратных клеток
- По краям поля расположены два выхода: **наивный** и **циничный**
- Фигура **Лисенка** начинает в центре поля

## Фигуры и их движение

### Лисенок

- За ход перемещается на **1 клетку** в любом направлении (8 направлений: вверх, вниз, влево, вправо, по диагоналям)
- Останавливается перед **стенами**
- Может попасть в **ловушку (волчью яму)** и пропускает один ход, после чего может двигаться дальше 

### Призраки (цель: поймать Лисенка)

**Красный призрак 🔴 — «Ладья»**

- Движется на **1 клетку** строго по прямой (вверх/вниз/влево/вправо)
- Выбирает направление, которое **приближает к Лисенку**
- Останавливается перед препятствиями

**Синий призрак 🔵 — «Слон»**

- Движется на **1 клетку** по диагонали
- Выбирает диагональ, **приближающую к Лисенку**
- Останавливается перед препятствиями

 Фиолетовый призрак 🟣 — «Конь»
- Движется в любом направлении
- Может перепрыгивать препятствия
- Но не может отправить лисенка на save point, а просто преграждает путь
- Движется в сторону Лисенка
 
## Препятствия на поле

### Стены 

- Непроходимые препятствия
- Блокируют Лисенка, красных и синих призраков

### Ловушки (волчьи ямы) 

- Попадает в них **только Лисенок**
- Призраки проходят мимо без последствий
- При попадании Лисенка в ловушку — партия начинается с последнего **save point** (или со старта, если чекпоинт не активирован)

### Save Points 

- Чекпоинты на поле
- Для активации Лисенок должен **пропустить ход**, находясь на этой клетке
- После активации — при столкновении с призраком или попадании в ловушку Лисенок возрождается на этой клетке (а не на старте)

## Порядок хода

1. **Игрок применяет скилл** (опционально, если есть доступные)
2. **Лисенок перемещается** (или пропускает ход для активации save point)
3. **Призраки перемещаются** по очереди в направлении Лисенка

## Система скиллов

Игрок имеет банк способностей, которые можно применять **перед** перемещением Лисенка.

### Доступные скиллы:

1. **Рывок** — преодолеть **3 клетки** по прямой с учетом препятствий (остановка перед стеной)
2. **Прыжок** — переместиться на любую клетку в **радиусе 2** (перепрыгивая препятствия)
3. **Призрачный шаг** — пройти сквозь **1 стену**
4. **Изгнание** — убрать **1 призрака** с поля навсегда
5. **Заморозка** — выбранный призрак **пропускает 3 хода**
6. **Замена** — поменяться местами с **любым призраком**

### Правила использования:

- Каждый скилл можно использовать **1 раз за партию**
- После использования скилл **не восстанавливается**
- Количество доступных скиллов зависит от **сюжетного прогресса** (от 1 до 6)

## Условия победы и поражения

### Победа ✓

Лисенок достигает одного из выходов (наивного или циничного)

### Поражение ✗

- **Столкновение с призраком** → возрождение на последнем активированном save point (или на старте)
- **Попадание в ловушку** → возрождение на последнем активированном save point (или на старте)

## Цель игры

Провести Лисенка из центра поля до одного из выходов, избегая призраков и ловушек, стратегически используя ограниченный набор способностей и активируя чекпоинты для сохранения прогресса.
