## Игровое поле

- Поле состоит из нечетного количества **9 × 9** квадратных клеток
- По краям поля расположены два выхода: **наивный** и **циничный**
- Фигура **Лисенка** начинает в центре поля

## Фигуры и их движение

### Лисенок

- За ход перемещается на **1 клетку** в любом направлении (8 направлений: вверх, вниз, влево, вправо, по диагоналям)
- Останавливается перед **стенами**
- Может попасть в **ловушку (волчью яму)** и пропускает один ход, после чего может двигаться дальше 

### Призраки (цель: поймать Лисенка)

**Красный призрак 🔴 — «Ладья»**

- Движется на **1 клетку** строго по прямой (вверх/вниз/влево/вправо)
- Выбирает направление, которое **приближает к Лисенку**
- Останавливается перед препятствиями

**Синий призрак 🔵 — «Слон»**

- Движется на **1 клетку** по диагонали
- Выбирает диагональ, **приближающую к Лисенку**
- Останавливается перед препятствиями

 Фиолетовый призрак 🟣 — «Конь»
- Движется в любом направлении
- Может перепрыгивать препятствия
- Но не может отправить лисенка на save point, а просто преграждает путь
- Движется в сторону Лисенка
 
## Препятствия на поле

### Стены 

- Непроходимые препятствия
- Блокируют Лисенка, красных и синих призраков

### Ловушки (волчьи ямы) 

- Попадает в них **только Лисенок**
- Призраки проходят мимо без последствий
- При попадании Лисенка в ловушку — партия начинается с последнего **save point** (или со старта, если чекпоинт не активирован)

### Save Points 

- Чекпоинты на поле
- Для активации Лисенок должен **пропустить ход**, находясь на этой клетке
- После активации — при столкновении с призраком или попадании в ловушку Лисенок возрождается на этой клетке (а не на старте)

## Порядок хода

1. **Игрок применяет скилл** (опционально, если есть доступные)
2. **Лисенок перемещается** (или пропускает ход для активации save point)
3. **Призраки перемещаются** по очереди в направлении Лисенка

## Система скиллов

Игрок имеет банк способностей, которые можно применять **перед** перемещением Лисенка.

### Доступные скиллы:

1. **Рывок** — преодолеть **3 клетки** по прямой с учетом препятствий (остановка перед стеной)
2. **Прыжок** — переместиться на любую клетку в **радиусе 2** (перепрыгивая препятствия)
3. **Призрачный шаг** — пройти сквозь **1 стену**
4. **Изгнание** — убрать **1 призрака** с поля навсегда
5. **Заморозка** — выбранный призрак **пропускает 3 хода**
6. **Замена** — поменяться местами с **любым призраком**

### Правила использования:

- Каждый скилл можно использовать **1 раз за партию**
- После использования скилл **не восстанавливается**
- Количество доступных скиллов зависит от **сюжетного прогресса** (от 1 до 6)

## Условия победы и поражения

### Победа ✓

Лисенок достигает одного из выходов (наивного или циничного)

### Поражение ✗

- **Столкновение с призраком** → возрождение на последнем активированном save point (или на старте)
- **Попадание в ловушку** → возрождение на последнем активированном save point (или на старте)

## Цель игры

Провести Лисенка из центра поля до одного из выходов, избегая призраков и ловушек, стратегически используя ограниченный набор способностей и активируя чекпоинты для сохранения прогресса.

            if (gameState.inTrap) {

                escapeBtn.style.display = 'block';

            } else {

                escapeBtn.style.display = 'none';

            }

        }

  

        function handleCellClick(x, y) {

            if (gameState.inTrap) {

                updateStatus('Вы в ловушке! Нажмите кнопку "Освободиться"');

                return;

            }

            if (gameState.activeSkill) {

                handleSkillClick(x, y);

                return;

            }

            const dx = x - gameState.fox.x;

            const dy = y - gameState.fox.y;

            if (Math.abs(dx) <= 1 && Math.abs(dy) <= 1 && !(dx === 0 && dy === 0)) {

                moveFox(dx, dy);

            }

        }

  

        function moveFox(dx, dy) {

            const newX = gameState.fox.x + dx;

            const newY = gameState.fox.y + dy;

            if (newX < 0 || newX >= BOARD_SIZE || newY < 0 || newY >= BOARD_SIZE) return;

            if (gameState.walls.find(w => w.x === newX && w.y === newY)) {

                updateStatus('Путь заблокирован стеной!');

                return;

            }

            gameState.fox.x = newX;

            gameState.fox.y = newY;

            checkGameState();

        }

  

        function checkGameState() {

            const exit = gameState.exits.find(e => e.x === gameState.fox.x && e.y === gameState.fox.y);

            if (exit) {

                showModal('Победа!', `Вы достигли ${exit.type === 'naive' ? 'наивного' : 'циничного'} выхода!`);

                return;

            }

            const trap = gameState.traps.find(t => t.x === gameState.fox.x && t.y === gameState.fox.y);

            if (trap) {

                updateStatus('Вы попали в ловушку! Нажмите кнопку "Освободиться"');

                gameState.inTrap = true;

                updateBoard();

                return;

            }

            endTurn();

        }

  

        function endTurn() {

            // Сохраняем текущие позиции призраков как предыдущие

            gameState.ghosts.forEach(ghost => {

                ghost.prevX = ghost.x;

                ghost.prevY = ghost.y;

            });

            createBoard();

            moveGhosts();

            const ghost = gameState.ghosts.find(g => g.x === gameState.fox.x && g.y === gameState.fox.y);

            if (ghost && ghost.type !== 'purple') {

                updateStatus('Призрак поймал вас!');

                respawnFox();

                return;

            }

            gameState.turn++;

            updateBoard();

        }

  

        function moveGhosts() {

            let ghostIndex = (gameState.turn - 1) % gameState.ghosts.length;

            const ghost = gameState.ghosts[ghostIndex];

            if (ghost.frozen > 0) {

                ghost.frozen--;

                updateStatus(`${ghost.emoji} заморожен. Осталось ходов: ${ghost.frozen}`);

                return;

            }

            let bestMove = null;

            let minDist = Infinity;

            const moves = ghost.type === 'red' ?

                [{dx: 0, dy: -1}, {dx: 0, dy: 1}, {dx: -1, dy: 0}, {dx: 1, dy: 0}] :

                ghost.type === 'blue' ?

                [{dx: -1, dy: -1}, {dx: -1, dy: 1}, {dx: 1, dy: -1}, {dx: 1, dy: 1}] :

                [{dx: 0, dy: -1}, {dx: 0, dy: 1}, {dx: -1, dy: 0}, {dx: 1, dy: 0},

                 {dx: -1, dy: -1}, {dx: -1, dy: 1}, {dx: 1, dy: -1}, {dx: 1, dy: 1}];

            moves.forEach(move => {

                const newX = ghost.x + move.dx;

                const newY = ghost.y + move.dy;

                if (newX < 0 || newX >= BOARD_SIZE || newY < 0 || newY >= BOARD_SIZE) return;

                if (ghost.type !== 'purple') {

                    if (gameState.walls.find(w => w.x === newX && w.y === newY)) return;

                }

                if (gameState.ghosts.find(g => g !== ghost && g.x === newX && g.y === newY)) return;

                const dist = Math.abs(newX - gameState.fox.x) + Math.abs(newY - gameState.fox.y);

                if (dist < minDist) {

                    minDist = dist;

                    bestMove = {x: newX, y: newY};

                }

            });

            if (bestMove) {

                ghost.x = bestMove.x;

                ghost.y = bestMove.y;

            }

        }

  

        function respawnFox() {

            if (gameState.lastSavePoint) {

                gameState.fox = {...gameState.lastSavePoint};

            } else {

                gameState.fox = {...gameState.startPos};

            }

            gameState.inTrap = false;

            createBoard();

        }

  

        function updateStatus(text) {

            document.getElementById('status').textContent = text;

        }

  

        function showModal(title, text) {

            document.getElementById('modal-title').textContent = title;

            document.getElementById('modal-text').textContent = text;

            document.getElementById('modal').classList.add('show');

        }

  

        // Кнопка освобождения из ловушки

        document.getElementById('escape-trap').addEventListener('click', () => {

            gameState.inTrap = false;

            updateStatus('Вы освободились из ловушки! Возвращение на save point...');

            respawnFox();

        });

  

        document.getElementById('skip-turn').addEventListener('click', () => {

            if (gameState.inTrap) {

                updateStatus('Вы в ловушке! Сначала освободитесь');

                return;

            }

            const savePoint = gameState.savePoints.find(s => s.x === gameState.fox.x && s.y === gameState.fox.y);

            if (savePoint) {

                gameState.lastSavePoint = {...gameState.fox};

                if (!gameState.activeSavePoints.find(a => a.x === savePoint.x && a.y === savePoint.y)) {

                    gameState.activeSavePoints.push(savePoint);

                }

                updateStatus('Save Point активирован!');

                endTurn();

            } else {

                updateStatus('Вы не на save point!');

            }

        });

            gameState = {

                fox: { x: CENTER, y: CENTER },

                startPos: { x: CENTER, y: CENTER },

                lastSavePoint: null,

                ghosts: [

                    { x: 1, y: 1, type: 'red', emoji: '🔴', frozen: 0, prevX: 1, prevY: 1 },

                    { x: 4, y: 7, type: 'purple', emoji: '🟣', frozen: 0, prevX: 4, prevY: 7 }

                ],

                walls: [],

                traps: [],

                savePoints: [],

                activeSavePoints: [],

                exits: [],

                usedSkills: [],

        // Keyboard controls

        document.addEventListener('keydown', (e) => {

        function activateSkill(skillId, btn) {

            document.querySelectorAll('.skill-btn').forEach(b => b.classList.remove('active'));

            btn.classList.add('active');

            gameState.activeSkill = skillId;

            const messages = {

                'dash': 'Выберите направление для рывка (3 клетки)',

                'jump': 'Выберите клетку в радиусе 2',

                'ghost': 'Выберите стену для прохода',

                'banish': 'Выберите призрака для изгнания',

                'freeze': 'Выберите призрака для заморозки',

                'swap': 'Выберите призрака для обмена местами'

            };

            updateStatus(messages[skillId]);

        }

  

        function handleSkillClick(x, y) {

            const skill = gameState.activeSkill;

            let success = false;

            if (skill === 'banish' || skill === 'freeze' || skill === 'swap') {

                const ghost = gameState.ghosts.find(g => g.x === x && g.y === y);

                if (!ghost) {

                    updateStatus('Выберите призрака!');

                    return;

                }

                if (skill === 'banish') {

                    // Временно убираем призрака за пределы поля

                    ghost.x = -10;

                    ghost.y = -10;

                    ghost.prevX = -10;

                    ghost.prevY = -10;

                    updateStatus('Призрак изгнан навсегда!');

                    success = true;

                } else if (skill === 'freeze') {

                    ghost.frozen = 3;

                    updateStatus('Призрак заморожен на 3 хода!');

                    success = true;

                } else if (skill === 'swap') {

                    const temp = {...gameState.fox};

                    gameState.fox = {x: ghost.x, y: ghost.y};

                    ghost.x = temp.x;

                    ghost.y = temp.y;

                    ghost.prevX = temp.x;

                    ghost.prevY = temp.y;

                    updateStatus('Вы поменялись местами с призраком!');

                    success = true;

                }

            } else if (skill === 'jump') {

                const dist = Math.abs(x - gameState.fox.x) + Math.abs(y - gameState.fox.y);

                if (dist <= 2 && dist > 0) {

                    gameState.fox.x = x;

                    gameState.fox.y = y;

                    updateStatus('Прыжок выполнен!');

                    success = true;

                } else {

                    updateStatus('Слишком далеко! Радиус: 2 клетки');

                    return;

                }

            }

            if (success) {

                gameState.usedSkills.push(skill);

                document.getElementById(`skill-${skill}`).disabled = true;

                document.querySelectorAll('.skill-btn').forEach(b => b.classList.remove('active'));

                gameState.activeSkill = null;

                checkGameState();

            }

        }

  

        initGame();
