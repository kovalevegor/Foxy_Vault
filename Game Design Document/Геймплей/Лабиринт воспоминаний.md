
---
## Игровое поле

Квадратная сетка **9×9 клеток**. Лабиринт генерируется процедурно при каждой новой игре алгоритмом recursive backtracker, что гарантирует полную связность: из любой клетки существует путь до любой другой.

Каждая клетка содержит участок коридора, определяемый набором открытых направлений: север, юг, запад, восток. Переход между двумя соседними клетками возможен только при наличии двустороннего коридора — оба прохода должны быть открыты с обеих сторон.

---

## Позиции

- **Старт игрока** — центральная клетка `(4,4)`
- **Левый выход** — клетка `(4,0)`, отмечена красной свечой
- **Правый выход** — клетка `(4,8)`, отмечена зелёной свечой

---

## Управление

|Клавиша|Действие|
|---|---|
|W|Шаг на север|
|S|Шаг на юг|
|A|Шаг на запад|
|D|Шаг на восток|
|R|Применить руну отпугивания|

Каждое нажатие — один шаг. Диагональное движение запрещено

---

## Свеча игрока

Игрок держит жёлтую свечу. Пока она горит, освещаются:

- клетка, на которой стоит игрок
- до четырёх соседних клеток — только те, куда ведёт открытый двусторонний коридор

Клетки за стенами остаются в темноте. Перемещение возможно только на освещённую клетку — кроме случая, когда свеча погашена (см. ниже).

---

## Темнота

Монстр может погасить свечу игрока. В этом состоянии:

- игрок видит только ту клетку, на которой стоит
- движение по-прежнему доступно во всех направлениях через открытые коридоры, без ограничения освещением
- чтобы снова зажечь свечу, нужно встать на клетку с зажжённой стационарной свечой

---

## Стационарные свечи

В лабиринте расположены **три стационарные свечи** в случайных тупиках (определяется при генерации). Изначально они не горят, но видны в темноте как тусклые огоньки.

**Поджечь:** встать на клетку со свечой, пока свеча игрока горит — стационарная свеча загорается и остаётся зажжённой до конца игры.

**Перезажечь свою свечу:** встать на клетку с уже горящей стационарной свечой, если своя свеча погашена.

Зажжённая стационарная свеча освещает только свою клетку.

---

## Выходы

Свечи выходов всегда видны в любой точке лабиринта независимо от освещения

Выход засчитывается, когда игрок, **стоя на exit-клетке**, делает шаг за пределы поля:

- стоя на клетке `(4,0)`, нажать **A** — выход через красный свет
- стоя на клетке `(4,8)`, нажать **D** — выход через зелёный свет

Наступание на exit-клетку само по себе не завершает игру — игрок может свободно уйти в другую сторону

---

## Монстр

В лабиринте присутствует один монстр. Он появляется спустя секунду после старта в случайной клетке, исключая клетку игрока, оба выхода, все стационарные свечи и любую клетку с прямой видимостью на игрока.

### Прямая видимость монстра

Монстр видит игрока, если они находятся в одной строке или одном столбце и между ними нет ни одной стены — луч проходит без препятствий по всей длине коридора

### Состояния монстра

**idle** — монстр не попадал в зону освещения игрока. Остаётся неподвижным и невидимым.

**spotted** — монстр впервые попал в зону освещения игрока. В этот ход монстр виден, но не действует. Это единственный момент, когда игрок может среагировать.

**chasing** — начинается на следующий ход после `spotted`. Монстр:

1. перед движением проверяет прямую видимость на игрока — если она есть, гасит свечу
2. делает один шаг по кратчайшему пути к текущей позиции игрока (BFS по коридорам)
3. уменьшает счётчик преследования

Преследование длится **4 хода**. Если за это время монстр не восстановил прямую видимость — растворяется и через короткую паузу появляется в новой случайной клетке по тем же правилам спауна.

Если во время преследования прямая видимость восстанавливается — монстр гасит свечу и возвращается в `spotted`, ожидая следующего хода игрока.

### Столкновение

Если после хода игрока его координаты совпадают с координатами монстра — **игрок погибает**. Игра завершается экраном смерти.

---

## Руна отпугивания

Одноразовая способность. Активируется клавишей **R** или кнопкой на экране.

**Условие активации:** монстр должен быть виден — находиться в зоне освещения свечи игрока либо в режиме `spotted` или `chasing` (принудительная видимость во время преследования).

**Эффект:** монстр немедленно телепортируется на случайную клетку лабиринта по правилам спауна, сбрасывается в `idle`. После использования руна недоступна до конца игры.

---

## Завершение игры

|Событие|Результат|
|---|---|
|Шаг за границу поля с exit-клетки|Победа|
|Совпадение координат с монстром|Поражение|

const Nd=0,Sd=1,Wd=2,Ed=3;

// ══════════════════════════════════════════════════════════

// MAZE GENERATION — recursive backtracker

// Guarantees full connectivity. Exits forced open after.

// ══════════════════════════════════════════════════════════

function generateMaze() {

  const m=[];

  for(let r=0;r<ROWS;r++){m[r]=[];for(let c=0;c<COLS;c++)m[r][c]=[0,0,0,0];}

  const vis=Array.from({length:ROWS},()=>new Array(COLS).fill(false));

  const shuffle=a=>{for(let i=a.length-1;i>0;i--){const j=Math.floor(Math.random()*(i+1));[a[i],a[j]]=[a[j],a[i]];}return a;};

  const stack=[[START_R,START_C]];

  vis[START_R][START_C]=true;

  while(stack.length){

    const[r,c]=stack[stack.length-1];

    const dirs=shuffle([[Nd,-1,0],[Sd,1,0],[Wd,0,-1],[Ed,0,1]]);

    let moved=false;

    for(const[dir,dr,dc] of dirs){

      const nr=r+dr,nc=c+dc;

      if(nr<0||nr>=ROWS||nc<0||nc>=COLS||vis[nr][nc])continue;

      m[r][c][dir]=1;

      m[nr][nc][[Sd,Nd,Ed,Wd][dir]]=1;

      vis[nr][nc]=true;

      stack.push([nr,nc]);

      moved=true;break;

    }

    if(!moved)stack.pop();

  }

  m[EXIT_R][EXIT_L_C][Wd]=1;

  m[EXIT_R][EXIT_R_C][Ed]=1;

  return m;

}

}

// Monster FSM: 'idle' | 'watching' | 'chasing'

// watching: monster is in player FOV and has LOS — stays still, extinguishes on next move if LOS holds

// chasing:  player broke LOS while monster was watching — monster moves toward player for mChase turns

let mR=-1,mC=-1,mMode='idle',mChase=0;

let runeAvailable=true; // one use per game

  

// ══════════════════════════════════════════════════════════

// DOM

// ══════════════════════════════════════════════════════════

const gridEl=document.getElementById('grid');

const playerTok=document.getElementById('player-token');

const monsterTok=document.getElementById('monster-token');

const stepsEl=document.getElementById('steps-counter');

const candleSt=document.getElementById('candle-status');

const statusBar=document.getElementById('status-bar');

const overlay=document.getElementById('overlay');

const overlayTitle=document.getElementById('overlay-title');

const overlaySub=document.getElementById('overlay-sub');

const overlayBtn=document.getElementById('overlay-btn');

const cellEls=[];

  

// ══════════════════════════════════════════════════════════

// BUILD GRID

// ══════════════════════════════════════════════════════════

function buildGrid(){

  gridEl.innerHTML='';cellEls.length=0;

  for(let r=0;r<ROWS;r++){

    cellEls[r]=[];

    for(let c=0;c<COLS;c++){

      const cell=document.createElement('div');

      cell.className='cell dark';

      const corr=document.createElement('div');

      corr.className='corridor';

      const[cn,cs,cw,ce]=MAZE[r][c];

      if(!cn)corr.classList.add('wall-n');

      if(!cs)corr.classList.add('wall-s');

      if(!cw)corr.classList.add('wall-w');

      if(!ce)corr.classList.add('wall-e');

      cell.appendChild(corr);

      if(r===EXIT_R&&c===EXIT_L_C){const x=document.createElement('div');x.className='exit-candle red';cell.appendChild(x);}

      if(r===EXIT_R&&c===EXIT_R_C){const x=document.createElement('div');x.className='exit-candle green';cell.appendChild(x);}

      if(scLit.hasOwnProperty(`${r},${c}`)){

        const sc=document.createElement('div');

        sc.className='static-candle unlit';

        sc.id=`sc-${r}-${c}`;

        cell.appendChild(sc);

      }

      gridEl.appendChild(cell);

      cellEls[r][c]=cell;

    }

  }

}

  

// ══════════════════════════════════════════════════════════

// LIT CELLS SET

// Player cell always included regardless of candle state.

// When candle is lit: +4 passable neighbors.

// Static candles: illuminate their own cell only.

// ══════════════════════════════════════════════════════════

function getLitSet(){

  const lit=new Set([`${pR},${pC}`]);

  if(candleLit){

    [[Nd,-1,0],[Sd,1,0],[Wd,0,-1],[Ed,0,1]].forEach(([dir,dr,dc])=>{

      if(!MAZE[pR][pC][dir])return;

      const nr=pR+dr,nc=pC+dc;

      if(nr<0||nr>=ROWS||nc<0||nc>=COLS)return;

      if(!MAZE[nr][nc][[Sd,Nd,Ed,Wd][dir]])return;

      lit.add(`${nr},${nc}`);

    });

  }

  SC_POSITIONS.forEach(([r,c])=>{if(scLit[`${r},${c}`])lit.add(`${r},${c}`);});

  return lit;

}

  

// ══════════════════════════════════════════════════════════

// UPDATE LIGHTING

// ══════════════════════════════════════════════════════════

function updateLighting(){

  const lit=getLitSet();

  for(let r=0;r<ROWS;r++)for(let c=0;c<COLS;c++){

    const el=cellEls[r][c];

    const key=`${r},${c}`;

    el.classList.remove('lit','player-cell','exit-left','exit-right','static-lit');

    if(lit.has(key)){

      el.classList.remove('dark');el.classList.add('lit');

      if(r===pR&&c===pC)el.classList.add('player-cell');

      if(r===EXIT_R&&c===EXIT_L_C)el.classList.add('exit-left');

      if(r===EXIT_R&&c===EXIT_R_C)el.classList.add('exit-right');

      if(scLit[key])el.classList.add('static-lit');

    }else{

      el.classList.add('dark');

    }

  }

  SC_POSITIONS.forEach(([r,c])=>{

    const sc=document.getElementById(`sc-${r}-${c}`);

    if(sc)sc.className='static-candle '+(scLit[`${r},${c}`]?'lit-yellow':'unlit');

  });

  playerTok.classList.toggle('candle-out',!candleLit);

  candleSt.textContent=candleLit?'свеча горит':'свеча погашена';

  candleSt.className=candleLit?'':'out';

}

  

// ══════════════════════════════════════════════════════════

// LINE OF SIGHT — same row or column, no walls between

// ══════════════════════════════════════════════════════════

function los(r1,c1,r2,c2){

  if(r1===r2&&c1===c2)return true;

  if(r1!==r2&&c1!==c2)return false;

  if(r1===r2){

    const mn=Math.min(c1,c2),mx=Math.max(c1,c2);

    for(let c=mn;c<mx;c++)if(!MAZE[r1][c][Ed]||!MAZE[r1][c+1][Wd])return false;

    return true;

  }else{

    const mn=Math.min(r1,r2),mx=Math.max(r1,r2);

    for(let r=mn;r<mx;r++)if(!MAZE[r][c1][Sd]||!MAZE[r+1][c1][Nd])return false;

    return true;

  }

}

  

// ══════════════════════════════════════════════════════════

// MONSTER RENDER

// ══════════════════════════════════════════════════════════

function renderMonster(){

  if(mR<0){monsterTok.style.display='none';monsterTok.classList.remove('force-visible','chasing');return;}

  const vis=getLitSet().has(`${mR},${mC}`);

  const forceShow=mMode==='chasing'||mMode==='spotted'; // always visible while spotted/chasing

  if(vis||forceShow){

    monsterTok.style.display='block';

    monsterTok.style.left=(mC*CELL_SIZE+CELL_SIZE/2)+'px';

    monsterTok.style.top=(mR*CELL_SIZE+CELL_SIZE/2)+'px';

    monsterTok.classList.toggle('chasing',mMode==='chasing');

    monsterTok.classList.toggle('force-visible',forceShow&&!vis);

  }else{

    monsterTok.style.display='none';

    monsterTok.classList.remove('force-visible');

  }

}

  

// ══════════════════════════════════════════════════════════

// BFS — one step toward target

// ══════════════════════════════════════════════════════════

function bfsStep(fr,fc,tr,tc){

  if(fr===tr&&fc===tc)return null;

  const vis=new Set([`${fr},${fc}`]);

  const q=[{r:fr,c:fc,first:null}];

  while(q.length){

    const{r,c,first}=q.shift();

    for(const[dir,dr,dc]of[[Nd,-1,0],[Sd,1,0],[Wd,0,-1],[Ed,0,1]]){

      if(!MAZE[r][c][dir])continue;

      const nr=r+dr,nc=c+dc;

      if(nr<0||nr>=ROWS||nc<0||nc>=COLS)continue;

      if(!MAZE[nr][nc][[Sd,Nd,Ed,Wd][dir]])continue;

      const key=`${nr},${nc}`;

      if(vis.has(key))continue;

      vis.add(key);

      const step=first||{r:nr,c:nc};

      if(nr===tr&&nc===tc)return step;

      q.push({r:nr,c:nc,first:step});

    }

  }

  return null;

}

  

function moveMonsterToward(tr,tc){

  const s=bfsStep(mR,mC,tr,tc);

  if(s){mR=s.r;mC=s.c;}

}

  

// ══════════════════════════════════════════════════════════

// SPAWN MONSTER — avoid player, exits, static candles, LOS

// ══════════════════════════════════════════════════════════

function spawnMonster(){

  const forbidden=new Set([`${pR},${pC}`,`${EXIT_R},${EXIT_L_C}`,`${EXIT_R},${EXIT_R_C}`]);

  SC_POSITIONS.forEach(([r,c])=>forbidden.add(`${r},${c}`));

  const cands=[];

  for(let r=0;r<ROWS;r++)for(let c=0;c<COLS;c++){

    if(!forbidden.has(`${r},${c}`)&&!los(r,c,pR,pC))cands.push([r,c]);

  }

  const pool=cands.length?cands:[[0,0]];

  const[r,c]=pool[Math.floor(Math.random()*pool.length)];

  mR=r;mC=c;mMode='idle';mChase=0;

}

  

// ══════════════════════════════════════════════════════════

// MONSTER FSM

//

// idle     → monster exists but is not seen. When player's

//            FOV includes the monster cell → 'watching'.

//

// watching → monster is visible AND has LOS to player.

//            On the NEXT player move, if LOS still holds:

//            extinguish. If player breaks LOS → 'chasing'.

//

// chasing  → monster moves 1 step toward player per turn.

//            Counter starts at 3. Each turn:

//              - move toward player

//              - if LOS restored → extinguish, back to 'watching'

//              - else decrement counter; if 0 → dissolve + respawn

// ══════════════════════════════════════════════════════════

function monsterTurn(){

  if(mR<0)return;

  

  // ── idle: monster not yet seen ──

  // When monster enters player FOV → transition to 'spotted'.

  // No movement this turn; player sees the monster for the first time.

  if(mMode==='idle'){

    const monVisible=getLitSet().has(`${mR},${mC}`);

    if(monVisible) mMode='spotted';

    return;

  }

  

  // ── spotted: monster was visible last turn ──

  // This turn: start chasing immediately and make the first move.

  // Also check LOS — if player is still in direct sight, extinguish candle.

  if(mMode==='spotted'){

    mMode='chasing';

    mChase=4;

    if(los(mR,mC,pR,pC) && candleLit) candleLit=false;

    moveMonsterToward(pR,pC);

    mChase--;

    if(mChase<=0){

      mR=-1;mC=-1;mMode='idle';

      setTimeout(()=>{ if(!gameActive)return; spawnMonster();renderMonster();updateRuneBtn(); },700);

    }

    return;

  }

  

  // ── chasing: move toward player each turn ──

  // If LOS holds at the moment of this move → extinguish candle.

  // mChase counts down regardless of LOS state.

  if(mMode==='chasing'){

    if(los(mR,mC,pR,pC) && candleLit) candleLit=false;

    moveMonsterToward(pR,pC);

    mChase--;

    if(mChase<=0){

      mR=-1;mC=-1;mMode='idle';

      setTimeout(()=>{ if(!gameActive)return; spawnMonster();renderMonster();updateRuneBtn(); },700);

    }

  }

}

  

// ══════════════════════════════════════════════════════════

// STATUS BAR

// ══════════════════════════════════════════════════════════

function updateStatus(){

  if(!gameActive){statusBar.textContent='';statusBar.className='';return;}

  const monVisible=mR>=0&&getLitSet().has(`${mR},${mC}`);

  if(mMode==='spotted'&&monVisible){

    statusBar.textContent='ОНО ТЕБЯ НАШЛО';statusBar.className='danger';

  }else if(mMode==='chasing'){

    statusBar.textContent='ПРЕСЛЕДОВАНИЕ  '+mChase;statusBar.className='chase';

  }else if(!candleLit){

    statusBar.textContent='свеча погашена — зажги ее';statusBar.className='';

  }else{

    statusBar.textContent='';statusBar.className='';

  }

}

function updatePlayerToken(){

  playerTok.style.left=(pC*CELL_SIZE+CELL_SIZE/2)+'px';

  playerTok.style.top=(pR*CELL_SIZE+CELL_SIZE/2)+'px';

}

  

// ══════════════════════════════════════════════════════════

// MOVE

// Movement rules when candle is OUT:

//   - Player can always move to an adjacent corridor cell,

//     even if it is not in the lit set (only current cell lit).

//   - Target cell must still be a valid corridor neighbor.

// ══════════════════════════════════════════════════════════

const DIR_MAP={'w':[Nd,-1,0],'s':[Sd,1,0],'a':[Wd,0,-1],'d':[Ed,0,1]};

const BUMP={'w':'translate(0,-5px)','s':'translate(0,5px)','a':'translate(-5px,0)','d':'translate(5px,0)'};

  

function tryMove(key){

  if(!gameActive)return;

  const k=key.toLowerCase();

  if(!DIR_MAP[k])return;

  const[dir,dr,dc]=DIR_MAP[k];

  const nr=pR+dr,nc=pC+dc;

  

  // Boundary exit

  if(nr<0||nr>=ROWS||nc<0||nc>=COLS){

    if(pR===EXIT_R&&pC===EXIT_L_C&&k==='a'){triggerWin('left');return;}

    if(pR===EXIT_R&&pC===EXIT_R_C&&k==='d'){triggerWin('right');return;}

    bumpP(k);return;

  }

  

  // Corridor validity

  if(!MAZE[pR][pC][dir]){bumpP(k);return;}

  if(!MAZE[nr][nc][[Sd,Nd,Ed,Wd][dir]]){bumpP(k);return;}

  

  // Lit check — ONLY when candle is burning

  // When candle is out, any valid corridor neighbor is reachable

  if(candleLit&&!getLitSet().has(`${nr},${nc}`)){bumpP(k);return;}

  

  // Perform move

  pR=nr;pC=nc;

  steps++;

  stepsEl.textContent='Шагов: '+steps;

  

  // Static candle interaction

  const scKey=`${pR},${pC}`;

  if(scLit.hasOwnProperty(scKey)){

    if(!scLit[scKey]&&candleLit)scLit[scKey]=true;   // ignite unlit candle

    if(scLit[scKey]&&!candleLit)candleLit=true;        // relight player candle

  }

  

  // Monster acts after player moves

  monsterTurn();

  

  updateLighting();

  updatePlayerToken();

  renderMonster();

  updateStatus();

  updateRuneBtn();

  

  // Death: player stepped onto monster's cell

  if(mR>=0&&pR===mR&&pC===mC){triggerDeath();return;}

  

  // No prompt on exit cell — player continues freely

}

  

function bumpP(k){

  playerTok.style.setProperty('--bd',BUMP[k]||'translate(0,0)');

  playerTok.classList.remove('bump');

  void playerTok.offsetWidth;

  playerTok.classList.add('bump');

}

  
  

// ══════════════════════════════════════════════════════════

// RUNE — one-use monster repel

// Active only when monster is visible (in getLitSet)

// ══════════════════════════════════════════════════════════

const runeBtnEl=document.getElementById('rune-btn');

  

function updateRuneBtn(){

  if(!runeAvailable){runeBtnEl.disabled=true;runeBtnEl.textContent='⟁ Руна использована';return;}

  // Rune available when monster is visually present: in FOV OR force-shown during spotted/chasing

  const monInFov=mR>=0&&getLitSet().has(`${mR},${mC}`);

  const monForced=mR>=0&&(mMode==='chasing'||mMode==='spotted');

  const monVisible=monInFov||monForced;

  runeBtnEl.disabled=!monVisible||!gameActive;

}

  

function activateRune(){

  if(!runeAvailable||!gameActive)return;

  if(mR<0)return;

  const monInFov=getLitSet().has(`${mR},${mC}`);

  const monForced=mMode==='chasing'||mMode==='spotted';

  if(!monInFov&&!monForced)return;

  runeAvailable=false;

  mR=-1;mC=-1;mMode='idle';mChase=0; // clears spotted/chasing too

  // Flash effect on token before hiding

  monsterTok.classList.remove('force-visible','chasing');

  monsterTok.style.display='none';

  setTimeout(()=>{

    if(!gameActive)return;

    spawnMonster();renderMonster();

  },800);

  updateLighting();updateRuneBtn();updateStatus();

}

// EXIT PROMPT (step on exit cell)

// ══════════════════════════════════════════════════════════

const overlayBtns=document.getElementById('overlay-btns');

  

function showExitPrompt(side){

  // Pause input but don't set gameActive=false yet

  gameActive=false;

  const L=side==='left';

  overlay.className='active exit-prompt';

  overlayTitle.textContent=L?'Красный Выход':'Зелёный Выход';

  overlaySub.textContent='Покинуть лабиринт?';

  overlayBtns.innerHTML='';

  const btnConfirm=document.createElement('button');

  btnConfirm.className='overlay-btn';

  btnConfirm.textContent='Выйти';

  btnConfirm.onclick=()=>triggerWin(side);

  const btnStay=document.createElement('button');

  btnStay.className='overlay-btn';

  btnStay.textContent='Остаться';

  btnStay.onclick=()=>{

    overlay.className='';overlay.classList.remove('active');

    gameActive=true;

  };

  overlayBtns.appendChild(btnConfirm);

  overlayBtns.appendChild(btnStay);

}

  

// ══════════════════════════════════════════════════════════

// WIN (confirmed exit)

// ══════════════════════════════════════════════════════════

function triggerWin(side){

  gameActive=false;

  const L=side==='left';

  overlay.className='active '+(L?'win-left':'win-right');

  overlayTitle.textContent=L?'Красный Свет':'Зелёный Свет';

  overlaySub.textContent='Выход найден за '+steps+' шагов';

  overlayBtns.innerHTML='';

  const btn=document.createElement('button');

  btn.className='overlay-btn';

  btn.textContent='Снова';

  btn.onclick=startGame;

  overlayBtns.appendChild(btn);

}

  

// ══════════════════════════════════════════════════════════

// DEATH

// ══════════════════════════════════════════════════════════

function triggerDeath(){

  gameActive=false;

  overlay.className='active death';

  overlayTitle.textContent='Темнота';

  overlaySub.textContent='Ты встретил его в темноте. Шагов пройдено: '+steps;

  overlayBtns.innerHTML='';

  const btn=document.createElement('button');

  btn.className='overlay-btn';

  btn.textContent='Начать заново';

  btn.onclick=startGame;

  overlayBtns.appendChild(btn);

}

  

// ══════════════════════════════════════════════════════════

// START / RESET

// ══════════════════════════════════════════════════════════

function startGame(){

  MAZE=generateMaze();

  initCandles();

  pR=START_R;pC=START_C;steps=0;candleLit=true;

  mR=-1;mC=-1;mMode='idle';mChase=0;

  runeAvailable=true;

  stepsEl.textContent='Шагов: 0';

  buildGrid();

  updateLighting();

  updatePlayerToken();

  monsterTok.style.display='none';monsterTok.classList.remove('force-visible','chasing');

  statusBar.textContent='';statusBar.className='';

  if(typeof updateRuneBtn==='function')updateRuneBtn();

  overlayBtns.innerHTML='';

  const btn=document.createElement('button');

  btn.className='overlay-btn';btn.textContent='Войти';btn.onclick=startGame;

  overlayBtns.appendChild(btn);

  gameActive=true;

  overlay.className='';overlay.classList.remove('active');

  setTimeout(()=>{if(!gameActive)return;spawnMonster();renderMonster();},900);

}

document.addEventListener('keydown', e => {

  if (!gameActive) return;

  

  let dir = null;

  

  switch (e.code) {

    case 'KeyW':

    case 'ArrowUp':

      dir = 'w';

      break;

    case 'KeyA':

    case 'ArrowLeft':

      dir = 'a';

      break;

    case 'KeyS':

    case 'ArrowDown':

      dir = 's';

      break;

    case 'KeyD':

    case 'ArrowRight':

      dir = 'd';

      break;

    case 'KeyR':

      e.preventDefault();

      activateRune();

      return;

  }

  

  if (dir) {

    e.preventDefault();

    tryMove(dir);

  }

});

  

let tx=0,ty=0;

document.addEventListener('touchstart',e=>{tx=e.touches[0].clientX;ty=e.touches[0].clientY;},{passive:true});

document.addEventListener('touchend',e=>{

  const dx=e.changedTouches[0].clientX-tx,dy=e.changedTouches[0].clientY-ty;

  if(Math.abs(dx)<12&&Math.abs(dy)<12)return;

  tryMove(Math.abs(dx)>Math.abs(dy)?(dx>0?'d':'a'):(dy>0?'s':'w'));

},{passive:true});

// overlay buttons are managed dynamically in startGame / triggerWin / triggerDeath
