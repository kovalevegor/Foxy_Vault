
## Отслеживаемые переменные

|Переменная|Значения|Откуда|
|---|---|---|
|`grimliss_tone`|caring / neutral / cold|Узел A|
|`lakka_trust`|high / low|Узел A|
|`player_frame`|saving / duty / manipulating|Узел A|
|`key_used`|true / false|Узел B–C|
|`tool_returned`|true / false|Узел C|
|`break_style`|careful / rough|Узел C|
|`foresight`|prepared / unprepared|Узел B|
|`foxcub_timing`|before / after|Узел B|
|`raven_noise`|triggered / silent|Узел E|
|`hammer_risk`|triggered / not|Узел E|

## Узел A — Разговор с Лаккой

Игрок должен открыть все пять тем. Три из них фиксированы по содержанию и свободны по порядку. Две дают выбор формулировки.

**Фиксированные темы (любой порядок):**

- О решении старейшин — Гримлис говорит, что решение неутешительное, без деталей.
- О времени — нужно выдвигаться до темноты.
- О Лисёнке — он на заднем дворе, нужно забрать перед уходом.

**Тема с выбором формулировки — О Гримлисе:**

- «Я обязан исполнить решение.» → `grimliss_tone = neutral`, `player_frame = duty`
- «Я знаю, как сделать это правильно.» → `grimliss_tone = cold`, `player_frame = manipulating`
- «Нам всем будет тяжело.» → `grimliss_tone = caring`, `player_frame = saving`

> **Колбэк #2 — запись реплики для узла D.** Точная формулировка этой реплики сохраняется и возвращается Лаккой позже.

**Тема с выбором формулировки — О том, что Лакка идёт с ними:**

- «Хорошо, что ты будешь рядом.» → `lakka_trust = high`
- «Это разумно с практической точки зрения.» → `lakka_trust = low`
- _(Молчание, просто кивнуть)_ → `lakka_trust = low`

> **После последней темы** — мысль Гримлиса на экране: _«Мне нужен медальон. Но он не будет работать, если она не отдаст его добровольно. Он у неё в сундучке с украшениями...»_ Формулировка мысли варьируется по `grimliss_tone`, факт неизменен.

**Условие завершения:** все пять тем закрыты.

## Узел B — Свободный обход дома (хаб)

После разговора с Лаккой задний двор, коридор, спальня и кабинет доступны в любом порядке. 
### Задний двор

**Клетка с воронами:**

- Осмотреть клетку → `foresight = prepared` (если до нахождения медальона)
- Открыть клетку сейчас → вороны внутри, дверца открыта
- Осмотреть мешок с просом → усиливает `foresight` если клетка уже замечена

**Лисёнок:**

- Взаимодействовать с Лисёнком _до_ кражи медальона → `foxcub_timing = before`
    - Реплика: _«Мы уже уходим?»_
- Взаимодействовать _после_ кражи → `foxcub_timing = after`
    - Реплика: _«Мы вернёмся?»_ → требует ответа игрока (нет / промолчать)

### Спальня Лакки

**Ключ от сундучка** лежит на прикроватном столике — Лакка его не прячет.

- Игрок может взять ключ → `key_used = true`
- Игрок может не заметить или проигнорировать → `key_used = false`

**Сундучок:** заперт. При попытке открыть без ключа и без инструмента — Гримлис говорит: _«Что-нибудь подходящее должно быть в кабинете.»_

### Кабинет Гримлиса

- Открыть окно кабинета изнутри → добавляет опцию «выйти через окно» в узле E
- Осмотреть ящик стола → найти **инструмент для взлома**

**Условие завершения:** найден сундучок и либо ключ, либо инструмент.

## Узел C — Взлом сундучка и поломка медальона

### Открытие сундучка

**Если `key_used = true`:** игрок открывает ключом → замок цел, следов нет, `action_traces = clean`
**Если `key_used = false`:** игрок применяет инструмент.

- Аккуратно → `action_traces = clean`, замок слегка деформирован, но неочевидно
- Торопливо → `action_traces = dirty`, замок деформирован заметно

### Поломка медальона

Внутри сундучка — медальон. Два варианта действия:

- **«Отломить аккуратно, по шву»** → `break_style = careful`
    - Гримлис (про себя): _«Она не заметит разницы. По крайней мере, не сразу.»_
- **«Отломить»** → `break_style = rough`
    - Гримлис (про себя): _«Вот и всё. Теперь у меня есть план.»_

После поломки сундук автоматически закрывается.

> **Механика #4 — Инструмент не убран.** Если игрок использовал инструмент и не вернул его в ящик стола вручную → `tool_returned = false`. Это активирует сцену в узле D.

**Условие завершения:** медальон повреждён, сундук закрыт.

---

## Узел D — Передача медальона («Пора собираться»)

Игрок возвращается к Лакке. В диалоге появляется тема **«Пора собираться»**.

Лакка уходит в дом собирать вещи. Гримлис предлагает помочь с украшениями → Лакка соглашается. Гримлис приносит медальон со сломанной петелькой, пытается застегнуть → не застёгивается.

---

### Срабатывание механики #4 (инструмент не убран)

Если `tool_returned = false`: перед тем как Гримлис успевает произнести реплику про починку, Лакка протягивает ему инструмент:

> _«Это твоё? Лежало у меня на столике.»_

Гримлис должен ответить:

- «Да, я искал его.» → нейтрально, Лакка принимает
- «Не знаю, как он там оказался.» → Лакка смотрит секунду: _«Ладно.»_
- _(Пожать плечами)_ → Лакка убирает инструмент молча — лёгкая напряжённость

---

### Реплика Гримлиса про медальон

_«Он сломался, дай я починю в кабинете.»_

---

### Обработка переменных из узла A (колбэк #2)

Лакка отдаёт медальон со следующей репликой — зависит от `grimliss_tone`:

| Тон Гримлиса в узле A | Реплика Лакки при передаче                                                    |
| --------------------- | ----------------------------------------------------------------------------- |
| `caring`              | _(без реплики, отдаёт молча, с лёгкой улыбкой)_                               |
| `neutral`             | _«Ты всегда умел исполнять. Вот, исполни и это.»_                             |
| `cold`                | _«Раз уж тебе важна практичность — на. Практичнее будет, если сам починишь.»_ |

---

### Обработка `break_style` (петелька)

|break_style|Реакция Лакки|
|---|---|
|`careful`|Отдаёт без замечаний|
|`rough`|Касается петельки пальцем: _«Странно, я не помню, чтобы она была такой... Ладно, почини.»_|

---

### Обработка `lakka_trust`

|lakka_trust|Темп сцены|
|---|---|
|`high`|Отдаёт медальон без паузы|
|`low`|Секунду смотрит на Гримлиса, потом кивает|

**Условие завершения:** медальон у Гримлиса, Лакка ушла. Факт передачи — инвариант.

---

## Узел E — Кабинет и вороны

Гримлис кладёт медальон на рабочий стол.

---

### Механика #6 — Удар молоточком как риск

Если игрок ударяет молоточком по столу для пробы звука → `hammer_risk = triggered`:

> Лакка кричит из другой комнаты: _«Гримлис? Ты уже начал?»_

Игрок выбирает ответ:

- _«Да, почти готово.»_ → Лакка успокаивается, не выходит
- _(Молчать)_ → Лакка идёт проверять. Гримлис должен успеть посадить воронов **до её прихода**: рассыпать пшено и открыть клетку (или выйти через окно). Если не успел — Лакка заходит и видит пустой стол. Она спрашивает: _«Что ты делаешь?»_ — нужно ответить.

---

### Поиск пшена и запуск воронов

Игрок находит пшено (на заднем дворе, возле клетки) и рассыпает на столе.

**Ветка 1 — `foresight = prepared`, клетка открыта заранее:**

- Вороны прилетают сами, начинают клевать.
- Сцена проходит без осложнений.

**Ветка 2 — `foresight = unprepared`, клетка закрыта:**

- Пшено рассыпано → тишина → Гримлис осознаёт проблему.
- Выйти через окно кабинета и открыть клекту.

---

### Механика #5 — Вороны шумят при закрытой клетке

Если клетка закрыта и Гримлис выходит за пшеном на задний двор, вороны начинают громко кричать → `raven_noise = triggered`:

> Лакка окликает из дома: _«Что там с воронами?»_

Гримлис отвечает немедленно:

- _«Всё нормально, я покормил их.»_ → Лакка замолкает
- _«Не знаю, наверное испугались чего-то.»_ → Лакка: _«Открой клетку, они так кричат когда заперты долго.»_ — фактически подсказка
- _(Молчать)_ → Лакка выходит на задний двор через пару секунд; Гримлис должен к этому моменту убрать пшено со стола или отвлечь её разговором

**Условие схлопывания:** вороны клюют пшено, ритмичный стук установлен.

---

## Узел F — Побег с Лисёнком

Гримлис забирает медальон, покидает кабинет через окно, идёт на задний двор.

### Механика #3 — Лисёнок и момент подхода

**Если `foxcub_timing = before`** (разговор был до кражи):

- Лисёнок ждёт спокойно.
- Гримлис просто зовёт его, они уходят.

**Если `foxcub_timing = after`** (Лисёнок спрашивал «Мы вернёмся?»):

- Зависит от ответа, данного ранее:
    - «Нет» → Лисёнок замедляется, смотрит на дом
    - _(Молчание)_ → Лисёнок идёт молча, не задаёт вопросов.

---

### Финальная сборка переменных

|Переменная|Эффект на финальный текст|
|---|---|
|`player_frame = saving`|Гримлис оглядывается на дом|
|`player_frame = manipulating`|Гримлис не оглядывается|
|`player_frame = duty`|Останавливается на секунду, потом идёт|
|`grimliss_tone = caring` + `lakka_trust = high`|Внутренний монолог: вина|
|`grimliss_tone = cold` + `lakka_trust = low`|Внутренний монолог: расчёт без сожаления|
|`grimliss_tone = neutral` + любой trust|Внутренний монолог: усталость, не вина и не триумф|

**Инварианты финала:** медальон унесён, Лисёнок с Гримлисом, Лакка обманута стуком воронов, направление — капище.

## Итоговая схема узлов

```
[A] Разговор с Лаккой
      → накапливает: grimliss_tone, lakka_trust, player_frame
      → запись конкретной реплики для колбэка в D
      → схлопывание: все 5 тем закрыты

[B] Свободный обход (хаб)
      → накапливает: key_used, foresight, foxcub_timing
      → опция окна кабинета для E
      → схлопывание: найден способ открыть сундучок

[C] Взлом + поломка
      → накапливает: break_style, action_traces, tool_returned
      → схлопывание: медальон повреждён

[D] Передача медальона  ← фильтрует A + C
      → колбэк реплики из A (grimliss_tone)
      → реакция на break_style (петелька)
      → срабатывание tool_returned (инструмент на столике)
      → схлопывание: медальон у Гримлиса [ИНВАРИАНТ]

[E] Кабинет + вороны  ← проверяет foresight, hammer_risk, raven_noise
      → риск от молоточка (hammer_risk)
      → шум воронов при закрытой клетке (raven_noise)
      → маршрут: гладко / через окно / через дом
      → схлопывание: стук установлен [ИНВАРИАНТ]

[F] Побег  ← финальная сборка всех переменных
      → реакция Лисёнка по foxcub_timing + предыдущий ответ
      → финальный монолог по grimliss_tone + lakka_trust + player_frame
      → схлопывание: уход к капищу [ИНВАРИАНТ]
```

|F|3 варианта реплики к Лисёнку; 3 варианта финального монолога|
