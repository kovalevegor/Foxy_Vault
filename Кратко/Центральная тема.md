%%  %%**Причина не имеет власти над исходом.**

Событие работает на тему, если:
- демонстрирует **разрыв между причиной и результатом**;
- или **подрывает иллюзию контроля через причинность**;
- или **показывает неизбежность исхода при разных причинах**.

От этой темы пляшут все события лора.
Карта соответствия событий лора теме:

| Событие                    | Соответствие теме          | Комментарий                                                                                                                                                                                                                       |
| -------------------------- | -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Рождения Хрёста и Гримлиса |                            |                                                                                                                                                                                                                                   |
| Знакомство с Лаккой        |                            |                                                                                                                                                                                                                                   |
| Сговор со Скиргейром       | Соответствует              | Сильный разрыв намерения и результата.                                                                                                                                                                                            |
| Набег и ложь               |                            |                                                                                                                                                                                                                                   |
| Рождение Нира              |                            |                                                                                                                                                                                                                                   |
| Договор с Хель             | Соответствует              | Структура договора воспроизводит модель медальона. Лакка пытается контролировать исход через сделку. Условие: привести род → получить время с мёртвыми. Но исход уже предопределен, ее родные мертвы, и ей не удастся их вернуть. |
| Смерти Скиргейра и Хрёста  | Соответствует              | Один исход - несколько причин.                                                                                                                                                                                                    |
| Лакка находит Сельви       | Соответствует              | Лакка использует медальон, чтобы гарантировать встречу с сестрой. Это - демонстрация иллюзии контроля через выбор исхода.                                                                                                         |
| Сожжение рынка             |                            |                                                                                                                                                                                                                                   |
| Гибель Сельви              | Соответствует              | Один исход - несколько причин.                                                                                                                                                                                                    |
| Проклятие Сельви           | Соответствует              | Причина (желание увидеть сестру) породила исход (проклятие), который Лакка не контролировала. Собственный инструмент обернулся против автора.                                                                                     |
| Донос Лакки                | Соответствует              | Один исход - две причины. На поверхности - забота об общине и санитарный контроль. На деле - исполнение договора с Хель.                                                                                                          |
| Самопожертвование Гримлиса | Не соответствует намеренно | Опровергаем тезис для завязки.                                                                                                                                                                                                    |
